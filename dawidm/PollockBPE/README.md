# pollockBPE

V2 autorskiego tokenizera byte-level BPE z pretokenizacją w stylu GPT-2.

Tokenizer jest używany jako podstawowy tokenizer modelu
[Pollock Mini LM 125M](https://huggingface.co/SlayerLab/pollock-mini-lm-125m).

## Zawartość

- artefakt tokenizera w formacie Hugging Face,
- konfiguracja tokenów specjalnych,
- kod użycia i weryfikacji tokenizera.
